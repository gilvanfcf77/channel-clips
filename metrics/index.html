metricas

metricas is a personal Google Cloud project, separate from the clips uploader. It is used by a script that runs on my own computer to read performance reports (views, watch time, engagement and estimated revenue) for the YouTube channels I own, so I can compare how my videos perform. It also searches public YouTube data (public videos, channels and comments) to help me choose which public conversations, such as podcasts and interviews, to feature on my channels.

What it does

  • Reads analytics and basic video information for my own channels.
  • Searches and reads public information about other creators' videos, channels and comments (titles, dates, durations, public view counts and public comments), the same information anyone can see on YouTube, only to choose content.
  • Is read-only: it never uploads, edits or deletes anything on YouTube.
  • Saves the reports as local files on my computer.

Who uses it

Only me. It is not offered to the public. It never signs in to any account other than my own, and it reads other creators' information only when that information is already public.
