Privacy Policy

Effective date: November 21, 2026

This policy describes how metricas (the "API client"), a personal Google Cloud project operated by Gilvan Ferreira Costa Filho, accesses, uses, stores and deletes data when it uses YouTube API Services. The API client is used by a script that runs on my own computer.

YouTube API Services and Google Privacy Policy

This API client uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Data obtained through YouTube API Services is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

Who uses this API client

The API client is used only by me, to read reports about the YouTube channels I own. It is not offered to the public, and no other person's account or data is accessed through it.

What data is accessed

When I connect one of my channels through Google sign-in (OAuth 2.0), the API client requests these read-only permissions:

  • youtube.readonly: to read the connected channel's name and ID and the list, titles and publish dates of its videos.
  • yt-analytics.readonly: to read the channel's YouTube Analytics reports (views, watch time, audience retention, likes, comments, shares, subscribers gained and lost, traffic sources).
  • yt-analytics-monetary.readonly: to read estimated revenue and ad performance reports for channels in the YouTube Partner Program.

Analytics reports are aggregated by YouTube and do not identify individual viewers. The API client does not access comments' content, viewer identities, private messages or any channel I do not own.

How the data is used

The data is used only to compare the performance of my own videos and channels and to plan my content. It is not used for advertising, profiling of people, or any other purpose.

How the data is stored

  • All data stays on my own computer. There is no server, cloud database or backup service involved.
  • OAuth tokens are stored in a local file accessible only to my Windows user account.
  • Reports are kept as local files (spreadsheets, a local database and text summaries).

How the data is shared

The data is not shared with, sold to or transferred to any third party.

Cookies and tracking

The API client does not use cookies, tracking technologies or third-party analytics, and it does not store or read information on any user's device or browser beyond the local files described above.

Deleting data and revoking access

  • Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions.
  • Local data can be deleted by removing the script's token and report files.
  • Stored YouTube data is kept only while I use the API client. When I stop using it, I revoke access and delete the local data.
  • To request deletion or ask a question, contact me at the address below. Requests are answered within 7 days.

Changes to this policy

If this policy changes, the effective date at the top of this page will be updated.
