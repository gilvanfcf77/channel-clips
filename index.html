Uses YouTube API Services

Personal uploader for my YouTube channel

clips is the name of my Google Cloud project and OAuth client. I use it with Clips Kitty, an open-source desktop application, to upload short clips made from my own videos to my own YouTube channel.

Who uses it: only me, the channel owner. It is not offered, sold or distributed to anyone else.

What it does with YouTube: uploads videos to my channel, sets their title, description and privacy status, and reads back the connected channel and the status of each upload.

Where it runs: on my own computer. There is no server, no user account and no data collection.
