Privacy Policy

Effective date: November 7, 2026

This policy describes how clips (the "API client"), a personal Google Cloud project operated by Gilvan Ferreira Costa Filho, accesses, uses, stores and deletes data when it uses YouTube API Services. The API client is used with Clips Kitty, an open-source desktop application that runs on my own computer.

YouTube API Services and Google Privacy Policy

This API client uses YouTube API Services. By using it, you agree to be bound by the YouTube Terms of Service. Data obtained through YouTube API Services is also subject to the Google Privacy Policy (https://policies.google.com/privacy).

Who uses this API client

The API client is used only by me, to publish videos to my own YouTube channel. It is not offered to the public, and no other person's account or data is accessed through it.

What data is accessed

When I connect my YouTube account through Google sign-in (OAuth 2.0), the API client requests these permissions:

  • youtube.upload: to upload videos to my channel.
  • youtube.readonly: to read which channel is connected and to confirm the privacy status YouTube applied to each upload.
  • youtube (only if playlist support is turned on): to add uploaded videos to my playlists.

The data accessed is limited to:

  • The connected channel's ID and name.
  • The ID, title, description and privacy status of videos uploaded through the API client.
  • The OAuth access and refresh tokens issued by Google.

No data about other channels, viewers, comments, subscribers or analytics is accessed.

How the data is used

The data is used only to upload my videos, to show which channel is connected, and to confirm that each upload succeeded with the intended privacy status. It is not used for advertising, profiling, analytics or any other purpose.

How the data is stored

  • All data stays on my own computer. There is no server, cloud database or backup service involved.
  • OAuth tokens are stored encrypted with Windows Data Protection (DPAPI), tied to my Windows user account.
  • The connected channel and upload records are kept in a local database used by the application.

How the data is shared

The data is not shared with, sold to or transferred to any third party. Videos go directly from my computer to YouTube. No internal or external party receives data from the API client.

Cookies and tracking

The API client does not use cookies, tracking technologies or third-party analytics, and it does not store or read information on any user's device or browser beyond the local files described above.

Deleting data and revoking access

  • Access can be revoked at any time on the Google security settings page: https://myaccount.google.com/permissions.
  • Disconnecting YouTube inside the application deletes the stored tokens and asks Google to revoke them.
  • Local data can be deleted by removing the application's data folder.
  • Stored YouTube data is kept only while the account is connected. When I stop using the API client, I disconnect it and delete the local data.
  • To request deletion or ask a question, contact me at the address below. Requests are answered within 7 days.

Changes to this policy

If this policy changes, the effective date at the top of this page will be updated.
